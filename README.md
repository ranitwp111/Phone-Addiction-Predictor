# Teen Phone Addiction Prediction System

## Overview
This project is a Machine Learning-based system that predicts the addiction level of teenagers based on their smartphone usage habits such as screen time, gaming hours, social media usage, sleep duration, and physical activity.

The model classifies addiction levels as:
- Low
- Moderate
- High

It also provides corrective suggestions to encourage healthier digital habits and reduce excessive phone dependency.

---

## 🚀Features
- Predicts teen phone addiction level
- Analyzes screen-time behavior
- Provides personalized recommendations
- Data preprocessing and model training
- Simple and easy-to-use implementation
